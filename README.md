# Creytix Homebrew tap

Install Creytix desktop apps with [Homebrew](https://brew.sh).

> The canonical source of `Casks/creytix-ide.rb` is the monorepo
> (`creytix-ide-desktop/homebrew/Casks/`), generated by `npm run cask:build`.
> This directory is mirrored into the standalone **`moshbenav-commits/homebrew-tap`**
> git repo that users actually tap. See `creytix-ide-desktop/HOMEBREW.md` for the
> release flow.

## Install

```sh
# One-time: add the tap (github.com is assumed, so no URL needed)
brew tap moshbenav-commits/tap

# Install the IDE
brew install --cask creytix-ide
```

The app self-updates (electron-updater), so you normally don't need
`brew upgrade`. To force Homebrew to re-pull the latest cask:

```sh
brew update && brew upgrade --cask creytix-ide
```

## Uninstall

```sh
brew uninstall --cask creytix-ide          # remove the app
brew uninstall --zap --cask creytix-ide    # also remove app data/caches/prefs
```

## First launch — unsigned build

The current build is **not yet code-signed / notarized**, so macOS Gatekeeper
quarantines it on first open. Until signing is in place, do one of:

- **Right-click the app → Open** (once), then **Open** in the dialog; or
- clear the quarantine flag:

  ```sh
  xattr -dr com.apple.quarantine "/Applications/Creytix IDE.app"
  ```

Once the app is signed + notarized with an Apple Developer ID, this step goes
away and `brew install --cask creytix-ide` "just works".
